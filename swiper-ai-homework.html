第 1 版提示词漏了"手动后不停止"

我的提示词
帮我用 Swiper 11 写一个轮播配置:可以无缝循环;每 3.2 秒自动翻页;底部有圆点分页器,圆点可以点击跳转;切换效果用 cube 立方体。
AI 回答

  autoplay: { delay: 3200 },

  effect: 'cube'
});
❌ 拖一次就停:AI 默认 disableOnInteraction: true,需求②"手动操作后不停止"不满足。

第 2 版点名"手动之后也不能停"

我的提示词(迭代)
上一版手动拖动之后自动播放会停。重新给一版:① 无缝循环;② 每 3.2 秒自动翻页,且用户手动拖动、点圆点之后也不能停;③ 圆点可点击跳转;④ effect 用 cube。
AI 回答 
new Swiper('#mySw4', {
  loop: true,
  autoplay: { delay: 3200, disableOnInteraction: false },
  pagination: { el: '.swiper-pagination', clickable: true },
  effect: 'cube'
});
✅ 四项全过:拖完 3.2 秒内照常继续自动翻页。

验证方法:两个轮播各拖动一次,等 5 秒——左边停、右边继续,差别直接可见。分页器选择器粘的时候换成了各自独立 id,避免两个轮播共用类名互相串(这正是答辩③的教训)。

答辩三问 · 我的回答

① 第一版提示词漏掉了哪个需求?

漏了"手动操作之后不停止"。我只写了"3.2 秒自动翻页",没想到 Swiper 默认把用户交互当成"停止自动播放"的信号。

② 你是在第几轮里"说清楚"的?

第 2 轮。直接点名"用户手动拖动、点圆点之后也不能停止自动播放",不再让 AI 猜。

③ AI 第一次给的代码错在哪?

autoplay 里少写 disableOnInteraction: false(默认 true,一拖就停);另外分页器用了类名 .swiper-pagination,在多轮播页面里会匹配到别人家的分页器,更稳的写法是指定自己的 id。

任务二 · creative 电影墙课堂没讲,AI 教我

课堂讲了 6 种 effect,Swiper 还有第 7 种 creative(自定义变换)。打开官方示例 swiper/demo/257-effect-creative.html,配合 AI 读懂 creativeEffect 的 transform 写法,为演示四新增第 7 个按钮「creative 电影墙」:上一张缩小左移带角度,下一张放大右侧进场。

学习过程(官方示例 + AI 追问记录)

我问 AI
我在看官方示例 257-effect-creative.html,creativeEffect 里 prev 和 next 各是一组 transform(translate / rotate / shadow)。请解释这个效果的工作方式和每个字段的方向含义,先不要改我的代码。
AI 回答(要点)
creative 效果会给每张 slide 按切换进度做"状态插值":prev 描述活跃张之前(已经看过)的卡片长什么样,next 描述活跃张之后(还没看)的卡片长什么样。translate 依次是 x / y / z:x、y 支持百分比(相对 slide 自身宽高),z 是像素级前后距离;rotate 是绕 x / y / z 三轴的角度(度);scale 是缩放倍数;shadow: true 给非活跃卡片加投影。切换时每张卡片从"当前状态"被插值到 prev / next 定义的目标状态。

我写的电影墙配置(已加进光影展演示四,第 7 个按钮)

if (btn.dataset.fx === 'creative') {
  cfg.creativeEffect = {
    prev: {
      shadow: true,
      translate: ['-92%', 0, -450],  // 整张退到左侧,后退 450px
      rotate: [0, 0, -10],           // 带 -10 度倾角
      scale: 0.85                    // 缩小
    },
    next: {
      shadow: true,
      translate: ['92%', 0, -200],   // 从右侧一个卡位外进场
      scale: 1.12                    // 放大进场
    }
  };
}

追问 AI + 我自己的话

Q:prev / next 的 transform 各控制什么?

我的回答:prev 控制"已经看过的上一张"的退场姿态——整张退到当前卡左侧一个卡位之外(translate -92%)、向后退 450 个像素、缩小到 0.85、绕 z 轴歪 -10 度、压上阴影;next 控制"即将进来的下一张"的进场姿态——停在当前卡右侧 92% 处、放大到 1.12 倍带着阴影等待,切换时从右侧滑进来,越靠近当前卡位缩放越回落到 1。一个管"走出去的样子",一个管"走进来的样子"。

现场实操 · 点箭头看电影墙切换

实操方法:点右侧箭头 → 下一张从右侧放大进场;点左侧箭头 → 上一张缩小左移带 -10 度倾角退场。这与光影展演示四第 7 个按钮「creative 电影墙」用的是同一套 creativeEffect 配置。

答辩两问 · 我的回答

① transform 里的百分号是相对谁的?

相对 slide 自身的尺寸:translate 的第 1 个百分比相对 slide 的宽度,第 2 个相对 slide 的高度,第 3 个值是像素级的 z 轴距离。不是相对容器,也不是相对窗口。

② 改一个数值让卡片转 20 度试试?

把 prev 的 rotate 从 [0, 0, -10] 改成 [0, 0, -20],左侧那张卡就会带 20 度的倾斜;next 改成 [0, 0, 20] 则是右侧那张带 20 度进场。我已在本地改过并实测生效。

答辩四问 · 我的回答

① 这段代码什么意思?

new Swiper('#wySw1', { keyboard: true }) —— 重建演示一轮播并启用 keyboard 模块;这个模块监听键盘方向键,enabled 时按 ← / → 分别触发 slidePrev / slideNext 完成翻页。

② AI 第一次给的哪里不对,你改了什么?

图片用了网络占位图链接,断网就裂,也不符合"图片用 AI 生成"的要求;wy-cap 说明层还丢了。我换成本地生成的 swiper-imgs/adora_1.jpg,补全标题与副标题,并把这张展品同步进四个演示轮播。

③ 新参数的作用?

keyboard: true 启用键盘控制;它默认带 onlyInViewport: true,只有轮播在可视区域内才响应方向键——光影展页面上有 4 个轮播,这样不会互相抢按键。

④ 现场把 delay 改成 6000 并解释预期变化?

autoplay.delay 从 3200 改成 6000(单位毫秒),每张图停留 6 秒才自动翻页,节奏明显变慢;因为配置里 disableOnInteraction: false,手动拖动之后它依然会按 6 秒的节奏继续播。
