用法

引入 cdn/lucide/lucide.min.js 后，用带有 data-lucide 的占位元素写下图标名；页面加载完成后， 脚本会把占位元素替换成真正的内联 <svg>。

因为拿到的是 SVG 元素，颜色、描边粗细、圆角端点都可以直接用 CSS 控制， 也可以复制这段 SVG 到别的页面里单独使用。 

<i data-lucide="house"></i>

<script src="cdn/lucide/lucide.min.js"></script>
<script>lucide.createIcons();</script>
