Font Awesome 字体图标

每个图标都被铸成字体里的一个字。写进页面时，它继承字号、颜色和字重， 也继承了印刷术对笔画的控制。

glyph / fa-house / solid 900

同一枚字形，放大到两百像素仍然边缘干净——这是字体图标最朴素也最可靠的地方。

用法

先引入 cdn/fontawesome/css/all.min.css，再给元素加上 fa-solid fa-house 这样的类名。字体图标靠伪元素渲染， 不能直接改 svg 的描边。

字体文件位于 cdn/fontawesome/webfonts/，页面不请求外部网络； 字号、颜色、字重都可以通过 CSS 继承，适合跟随正文排版。
