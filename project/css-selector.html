盒模型

盒模型:content(内容) → padding(内边距) → border(边框) → margin(外边距),从内到外依次包裹。

Hello Box
.box {
    width: 200px;
    padding: 20px;              /* 内边距:内容和边框之间的距离 */
    border: 3px solid #4a90d9;  /* 边框:盒子的轮廓 */
    margin: 20px;               /* 外边距:盒子和盒子之间的距离 */
}

补充:设置 box-sizing: border-box 之后,width 就包含 padding 和 border 了,盒子不会被撑大。

CSS 选择器优先级

多个选择器同时选中一个元素时,优先级从低到高:标签选择器 < 类选择器 < ID 选择器 < 行内样式 < !important。权重可以记成四位数:行内 1000、ID 100、类 10、标签 1。

我被标签选择器选中(0,0,0,1) → 蓝色

我被标签+类选中(0,0,1,1) → 绿色

我被标签+类+ID选中(0,1,1,1) → 橙色

行内样式写的灰色,但是 !important 更大,强制变红

CSS Diner 通关游戏答案

  1. plate类型选择器:选中所有 plate 标签
  2. bento类型选择器:选中所有 bento 标签
  3. #fancyID 选择器:选中 id="fancy" 的唯一元素
  4. plate apple后代选择器:选中盘子里的苹果
  5. #fancy pickleID + 后代:fancy 盘子里的黄瓜
  6. .small类选择器:选中所有 class="small" 的元素
  7. orange.small标签 + 类(连写):既是 orange 又带 small 类
  8. bento orange.small组合:便当盒里的小橙子
  9. plate, bento逗号并列:选中所有 plate 或 bento
  10. *通配选择器:选中页面上所有元素
