实现要点

切换逻辑集中在 js/tabs.js，用事件监听加事件委托绑定标签栏，任何页面只要按 data-tzk-tabs 标注结构，引入同一个脚本即可复用。 

// 事件监听：委托绑定在标签栏上
tablist.addEventListener('click', jsTabsHandleClick);

// 第一步：清除所有选项卡的选中状态
tabs[i].classList.remove('tzk-tabs__tab--active');
panels[i].classList.remove('tzk-tabs__panel--active');

// 第二步：再设置当前元素的选中状态
current.classList.add('tzk-tabs__tab--active');
